# VIPFucker

VIPFucker 是一个面向已适配 Android 应用的 LSPosed 模块。它通过内置规则为目标应用加载对应功能，并在模块界面集中显示适配列表、安装状态和作用域状态。

> 项目尚未提供正式安装包。首个版本发布后，请从本仓库的 [Releases](https://github.com/qianqi32/vipfucker/releases) 页面下载；不要从非官方渠道获取 APK。

| --- | --- | --- |
| CapyPlayer | 1.1.6 | Pro 功能 |

具体效果取决于目标应用版本和设备环境；上述列表不保证对其他版本有效。

## 安装要求

- Android 8.0（API 26）或更新版本。
- 已安装支持模块 API 102 的 LSPosed 环境，并启用本模块。
- 需要安装对应的目标应用，并在 LSPosed 中授权该应用的作用域。

## 使用方法

1. 从 [Releases](https://github.com/qianqi32/vipfucker/releases) 下载并安装已签名的 APK。
2. 在 LSPosed 中启用 VIPFucker，为需要使用的目标应用勾选作用域。
3. 打开 VIPFucker，查看适配应用及作用域状态；若从模块内申请作用域，请在 LSPosed 通知中确认。
4. 重启目标应用进程后检查功能。部分功能在应用启动阶段生效，不能仅靠切换界面即时应用。

更新模块时请使用同一签名证书发布的 APK。不同签名的安装包无法直接覆盖安装；已安装过较高 `versionCode` 的本地开发包也无法直接降级覆盖。

## 常见问题

**模块界面显示未连接 LSPosed？** 请确认 LSPosed 已启用模块，然后重新打开 VIPFucker。

**应用已在列表中但没有生效？** 检查 LSPosed 作用域是否已授权、目标应用版本是否与推荐版本一致，并重启目标应用。列表显示应用不等于框架已经授予作用域。

**更新后仍未生效？** 先重启目标应用进程。模块仅对部分满足特定条件的规则支持热重载，其他情况仍需重启。

## 关于源码与发布

源码保存在私有 Gitea 仓库；这个 GitHub 仓库用于项目介绍、自动构建配置和 APK 发布，不提供源码镜像。发布工作流从私有仓库获取对应版本的代码，构建并验证签名后上传安装包。当前项目与上述目标应用的开发者没有关联。
