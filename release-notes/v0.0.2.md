VIPFucker v0.0.2

> 新增
> - 新增一木记账、阅读记录、记得日子、AppShare、记得记账和 Todo清单适配
> - 重做管理界面，提供 Material 3 与 MIUIX 两种风格及可调外观
> - 新增简体中文、繁体中文和英语界面，以及首次使用协议
>
> 调整
> - 更新弹窗展示版本号和更新内容，并提供下载及取消操作
> - 发布包启用 R8 混淆，内置适配规则以压缩资源形式打包
> - 更新模块或规则后重启目标应用进程即可重新加载，不再使用 Yamby 热重载

支持 Android 8.0 及以上系统，需使用支持模块 API 102 的 LSPosed 环境。MIUIX 液态玻璃效果仅在 Android 13 及以上提供；目标应用适配以模块内标注的推荐版本为准。
