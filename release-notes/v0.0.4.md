# VIPFucker v0.0.4 更新内容草稿

> 未发布，仅供审阅。推送此文件不会创建 GitHub Release，也不会提供新版 APK。

## 界面

- 新增 COUI 风格，Material 3、MIUIX 和 COUI 均可选择标准底栏或悬浮底栏；统一选项名称并调整 COUI 悬浮底栏尺寸。
- 调整三种风格的首页状态信息，以 LSPosed 连接状态和设备信息为主，不再显示无关的 Root 状态。
- 首次使用协议页采用 Material 3 风格的单页阅读布局，只需一次确认。
- 重做新版本提示弹窗，更新内容可滚动阅读；可跳过当前版本的自动提醒，手动检查仍能查看。

## 适配

- 新增 TickTick、动漫共和国、知犀思维导图、醒图、小熊油耗、喜马拉雅、星笔记、长佩阅读、今日水印相机、扇贝阅读和扇贝单词英语版的规则及推荐作用域。
- 调整部分已有适配的专用 Hook 代码归属。晋江小说阅读未纳入本次适配列表。

新增适配已写入当前源码与调试包，但目标应用中的实际效果仍需按推荐版本和设备环境逐项验收。正式发布前还需核对发布签名、内置规则与推荐作用域；本草稿不代表发布承诺。
